# 氛围着色器美术升级：山色（landscape）

> 对应版本：v2.5.2 · 2026-09-08
> 目标：把氛围背景从"暗色抽象雾"升级为"山清水秀"的自然场景，同时保住 v2.5.1 建立的性能护栏。

## 设计依据

参考了三份经典 Shadertoy 作品，但**不照搬实现**——它们是桌面端的玩法，直接整屏搬到手机必卡：

| 参考 | 取了什么 | 为什么不照搬 |
| --- | --- | --- |
| iq 的山地风景（分层山脊 + 大气透视 + 体积云） | 山脊分层构图、坡向光照、按距离褪向天色的空气透视 | 原作 400 步地形光线步进 + 128 步体积云 + 前帧重投影累积，依赖多 buffer 时域降噪 |
| TDM《Seascape》 | 水面着色模型：菲涅尔天空反射 + 水体色 + 法线上的太阳高光 | 原作 32 步二分搜索求海面交点；我们用水线镜像 + fbm 波法线替代 |
| sonicether《Gargantua》 | 调色思路：色调映射 + 对比度曲线 + 分级 | 原作 4 个 buffer 的 bloom 管线；现阶段复用主 pass 的 Reinhard + sRGB |

## 已落地：`landscape` 模式（模式 7，名称"山色"）

全部屏空间实现，无光线步进，每像素最坏约 15～18 次 fbm 采样（与现有 aurora 模式同量级）：

- **天空**：地平线暖雾 → 天顶蓝的梯度，带宽幅暖光和近太阳眩光（固定主光 `LSUN`，左上前方的关键光）。
- **云**：fbm 覆盖率 + 朝太阳二次采样做云的明暗（亮顶暗底），极慢漂移。
- **四层山脊**：远处层小而密、近处层大而疏；每层独立种子；坡向用有限差分求斜率，太阳侧受光、背侧沉入阴影；按层深做空气透视（远山褪向天色）；山顶部混入受光的干草色。山脚基线略高于水线，留出"对岸"的空气带。
- **湖面**：水线镜像整个上半场景（山与云都倒影），fbm 波动随近岸增大——远岸如镜、近岸微漾；菲涅尔用无 pow 的三次乘积（GLSL 的 pow 负基数为未定义行为）；Seascape 式太阳高光骑在波法线上；水线处一条空气带把两个平面缝起来。
- **接线**：`背景 → 山色` 手动可选；天气"晴"时默认 2/3 概率呈现山色（其余为海面）；与其他模式的过渡混合（uBlend）照常工作。

性能护栏沿用 v2.5.1：移动端 0.66× 内部分辨率、fbm 3 八度、30fps 上限（编辑器打开时 12fps）。

## 调色说明

美术常数（山的绿、水的青、雾的灰蓝）是按现有色调映射管线（Reinhard 2.05 + sRGB）推算的目标值，**未在真机上逐帧校色**——上真机后如偏灰/偏暗，优先调 `lsScene` 里 `forest` 的三个 mix 端点和 `aerial` 系数，其次调 `lsSky` 的天顶蓝。改动都集中在 `Atmosphere.tsx` 的 `ls*` 函数族，不影响其他模式。

## 路线图（按性价比排序）

1. **ocean 模式升级**：现有 ocean 是平面波纹 + 反光带；可换成 Seascape 的 `sea_octave` 八度叠加直接驱动法线（平面解析求交，免光线步进），海面会立刻"活"。
2. **单 pass bloom**：借 Gargantua 的多级模糊思路，在主 pass 里用 mipmap LOD 采样近似 8 级 blur，太阳眩光和高光会泛出来，不用加 render target。
3. **时域累积**（iq 的 iChannel0 技巧）：前一帧存到 render target，重投影混合当前帧，静止画面渐进细化——可换来"提高分辨率不掉帧"。
4. **按回忆调色**：山色目前固定美术配色不受照片调色板污染；后续可给 `uTint` 一个 10～15% 的低权混入，让每篇日记的山色有细微个体差异。
