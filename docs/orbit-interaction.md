# 首页星球轨道交互（Orbit）

> 对应版本：v2.6.0 · 2026-09-08
> 目标：把"轮播翻页"换成"在一个连续空间里滑行"。三个记忆体同场共存，切换是轨道位移，不是页面切换。

## 架构

`components/memory/Orbit.tsx` 取代了旧的每记录一个 `Planet`：

- **常驻场景**：一个 WebGLRenderer、一个场景、一个相机，挂载期创建，视图切换也不重建。星球是对象池里的 `THREE.Points`（上限 6 个），几何体换入换出，对象本身复用。
- **连续轨道**：每颗星球的世界坐标 = `(entryIndex - track) × SPACING`，`track` 是一个连续的浮点位置。切换只是 `track` 的弹簧运动（`orbitMotion.ts`：刚度 42、阻尼 9.2，~0.55s 收敛、~4% 过冲的轻微弹性）。星球两侧沿浅弧后退（`z = -0.3·o²`），形成纵深。
- **窗口与预载**：轨道中心 ±2 的记录保持活动对象；几何体（字形/照片采样）在空闲时段串行构建并缓存，切换前已就绪。离开窗口的几何体即时释放。
- **视觉层级**：`focusFactor`（中央 1 → 旁侧 0.55）连续插值亮度、饱和与透明度；`planetScale`（1 → 0.7）插值尺寸。位置、缩放、亮度每帧随 `track` 连续变化，没有动画结束时的状态跳变。

## 输入（全部驱动同一套轨道）

| 输入 | 行为 |
| --- | --- |
| 左右箭头 | `targetIndex ± 1`，弹簧滑行；快速连点在中途合并（重定目标，不锁定） |
| 鼠标/触控横向拖动 | `track` 跟手（px→世界单位换算），松手后按速度投影惯性滑行并吸附最近记录 |
| 点击侧边星球 | 命中测试（世界坐标）→ 移到中央，**不**打开详情 |
| 点击中央星球 | 打开日记详情（dive：中央星球放大外扩，旁侧淡出） |
| 滚轮 / 触控板捏合 / 双指捏合 | 相机距离缩放，`clampZoom` 限制在 0.75×–1.8×，平滑插值，不切换记录 |
| 双击 / 双击轻触 | 恢复默认视角 |

细节：捏合抬指后重定拖动原点（防止残留手指用过期坐标瞬移）；拖动跨过 5px 阈值后点击失效；`prefers-reduced-motion` 直接跳变；dive/return 期间输入锁定。

## 状态与 React 的边界

- React 只在轨道**沉降**时收到 `onSettle(index)` 更新选中记录；滑行期间标题/序号淡出（`caption-faded`），沉降后随新内容淡入。
- 创建/归档跳转走 `snap` 计数器：轨道瞬间对齐（不滑行）再进详情。
- 缩放与轨道位置存在组件 ref 里：进详情再返回，视角原样恢复。
- 编辑中的记录每 ~900ms 比对版本（updatedAt + 封面 + 种子），变化则在空闲时段重建几何体，**原位换入**，旧点阵保持显示到换入完成。

## 验收对照

- 左中右三球同场 ✓（对象池 + 弧形轨道；移动端两侧露出边缘）
- 切换是空间移动 ✓（连续 `track`，无淡出重建、无横向切屏）
- 箭头/拖动/滑动/侧球点击统一 ✓；侧球先居中、中央球才进详情 ✓
- 滚轮/触控板/捏合缩放 ✓（0.75–1.8×，双击复位）
- 常驻 renderer、对象池、±2 预载 ✓；无原图占位叠底（poster 已删除）✓
- 连续快切合并状态 ✓（弹簧重定目标，`tests/orbitMotion.test.ts` 钉住收敛与有界性）
- 详情返回恢复视角 ✓（轨道组件保持挂载）
